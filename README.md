<details>
<summary><b>🔍 Nmap — Network Scanner</b></summary>

### What it does
Nmap (Network Mapper) is the industry-standard tool for network discovery and security auditing.

### Key Commands I Use
```bash
# Basic scan
nmap -sV -sC -p- <target>

# Stealth SYN scan
nmap -sS -T4 <target>

# OS detection + version + script
nmap -A <target>

# Scan specific ports
nmap -p 22,80,443,8080 <target>

# Save output
nmap -oN output.txt <target>
```

### CEH Exam Tips
- Know the difference between TCP Connect, SYN, UDP, XMAS, NULL, FIN scans
- Understand which scans bypass firewalls vs don't
- XMAS scan sets FIN, PSH, URG flags — looks like a Christmas tree 🎄

<details>
<summary><b>🕷️ Burp Suite — Web App Security Testing</b></summary>

### What it does
Burp Suite is the go-to tool for web application penetration testing and bug bounty hunting.

### Key Features I Use
```
Proxy      → Intercept HTTP/HTTPS requests between browser and server
Repeater   → Manually modify and resend requests
Intruder   → Automated payload injection (SQLi, XSS fuzzing)
Scanner    → Automated vulnerability detection (Pro version)
Decoder    → Encode/decode Base64, URL, HTML, etc.
```

### Bug Bounty Workflow
```
1. Set up FoxyProxy → route traffic through Burp (127.0.0.1:8080)
2. Browse target → capture all requests in Proxy history
3. Identify interesting endpoints (login, upload, API)
4. Send to Repeater → manually test each parameter
5. Test for XSS: <script>alert(1)</script>
6. Test for SQLi: ' OR '1'='1
7. Document everything with screenshots
```

### Vulnerabilities I Found Using Burp
- [x] Reflected XSS — modified parameter in GET request
- [x] Stored XSS — injected payload in profile field
- [x] Cookie Hijacking — identified missing HttpOnly flag
- [ ] SSRF — testing next...
